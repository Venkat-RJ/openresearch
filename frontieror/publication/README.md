# Supporting publication records

These files supplied the article's supporting notebook, examples and figures. The [three study guides](../README.md) are the starting point for the main results.

- [Recorded scheduling revision](study-evidence/scheduling/research-decision.json): the V1-to-V2 development comparison and recorded next decisions.
- [Scheduling workflow provenance](study-evidence/scheduling/workflow-provenance.json): custom tools and saved source identities.
- [Additional scheduling files](study-evidence/scheduling/): example input/output, checking records and comparison data used by the notebook.
- [Featured-case records](evidence/tiny/): the inputs, code and saved decisions used in the delivery, cutting, transit, kitchen and bus-duty explanations.
- [Publication figures](figures/) and [editable diagrams](diagrams/).

Some records duplicate files in the study directories so that the original publication references remain traceable. They represent the same experiments and are counted once in the article.
