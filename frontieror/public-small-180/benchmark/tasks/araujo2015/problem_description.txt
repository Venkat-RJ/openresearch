# Problem Description

A manufacturing facility produces multiple items on a single machine over a finite planning horizon divided into discrete time periods. The input data specifies the number of items and the number of periods, the demand for each item in each period, a setup cost for each item in each period (incurred when the item is produced in that period), a per-unit holding cost for each item in each period (charged on inventory carried at the end of the period), a per-unit variable production cost for each item in each period, a setup time for each item in each period (consumed from the period's capacity whenever that item is produced), a per-unit variable production time for each item in each period, a time capacity for each period, and a per-unit cost for initial inventory for each item.

The planner must determine, for each item in each period, the quantity to produce, whether a setup is performed, and the inventory held at the end of the period. The planner must also determine the amount of initial inventory for each item, which is stock available at the start of the first period without requiring a setup.

In every period, the inventory of each item carried from the previous period plus the production of that item in the current period must equal the demand for that item in the current period plus the inventory carried forward to the next period. All inventory at the end of the final period must be zero; that is, no stock may remain after the last period. Production of an item in a given period can only occur if a setup for that item is performed in that period. Furthermore, the quantity produced of any item in a period cannot exceed the smaller of two values: the period's total time capacity minus that item's setup time in that period divided by that item's per-unit production time in that period, and the total remaining demand for that item from that period through the end of the horizon. In each period, the total time consumed by all setups and all production across every item must not exceed the period's time capacity.

The goal is to minimize total cost, which is the sum of four components: the cost of initial inventory (the per-unit initial inventory cost times the initial stock for each item, summed over all items), the setup costs (the setup cost times the setup indicator for each item in each period, summed over all items and periods), the variable production costs (the per-unit production cost times the production quantity for each item in each period, summed over all items and periods), and the holding costs (the per-unit holding cost times the end-of-period inventory for each item in each period, summed over all items and periods).
