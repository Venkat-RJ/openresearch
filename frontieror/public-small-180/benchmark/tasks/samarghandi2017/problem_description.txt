# Problem Description

A manufacturing facility processes a set of jobs on machines arranged in series, forming a flow shop. Every job must visit all machines in the same fixed order, from the first machine through the last machine, and every job has a known processing time on each machine. All jobs are available for processing at time zero, no preemption or interruption of any operation is permitted, each machine can handle only one job at a time, and no job can be on more than one machine simultaneously. Crucially, no waiting is allowed between consecutive operations of the same job: once a job finishes on one machine, it must start immediately on the next machine with zero delay. Each job also has a given due date by which its last operation must be completed; this is a hard requirement that cannot be violated.

Because of the no-wait restriction, the schedule is fully determined by a single permutation of the jobs, since the order in which jobs visit the machines is identical across all machines. The planner must therefore determine the sequence in which all jobs are processed. For each job, a start time on each machine is implicitly determined by the sequence and the no-wait rule: the start time of a job's operation on the next machine equals the start time on the current machine plus the processing time on the current machine. Operations of different jobs must not overlap on any machine: if one job is sequenced immediately after another, the successor's operation on every machine must not begin before the predecessor's operation on that same machine has finished. Every job's completion time on the last machine must not exceed that job's due date.

The goal is to find the job sequence that minimizes the makespan, defined as the latest completion time among all jobs on the last machine. The makespan equals the maximum, over all jobs, of the sum of that job's start time on the last machine and its processing time on the last machine. The input data consists of the number of jobs, the number of machines, a processing time for each combination of job and machine, and a due date for each job.

The sequencing requirement is that the total number of immediate-successor links among the jobs equals one fewer than the total number of jobs, each job has at most one immediate predecessor and at most one immediate successor in the sequence, no job can be its own successor, and for any pair of jobs at most one of the two possible predecessor-successor relationships holds. Together these rules ensure the jobs form a single chain covering every job exactly once. When a job is sequenced immediately after another, the start time of every operation of the successor on each machine must be at least as large as the start time of the corresponding operation of the predecessor plus the predecessor's processing time on that machine; when the two jobs are not adjacent this ordering requirement is relaxed via a sufficiently large constant. The no-wait rule is enforced as a strict equality: for every job and every machine except the last, the start time on the next machine equals the start time on the current machine plus the current processing time. The due-date rule requires that, for every job, the start time on the last machine plus the processing time on the last machine does not exceed the job's due date.
