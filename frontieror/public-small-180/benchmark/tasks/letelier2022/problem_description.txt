# Problem Description

A facility must schedule a set of items across a discretized time horizon using identical capacitated bins. The input specifies a set of items, each with a known positive weight no greater than the bin capacity. A positive integer gives the common capacity shared by all bins. The time horizon consists of a set of consecutive time periods numbered from one up to a given upper bound on the number of periods. In each time period, up to a given maximum number of bins may be used; when that maximum is unrestricted (infinite), any number of bins may be used in any period. A directed graph over the items encodes pairwise timing relationships: each arc from one item to another carries an integer-valued lag (which may be positive, zero, or negative). A positive lag on an arc from a first item to a second item means that the time period assigned to the second item must exceed the time period assigned to the first item by at least that lag value. A negative lag on the reverse arc from the second item back to the first item encodes an upper bound on how far apart the two items may be scheduled, so that the pair of arcs between two items together confine the difference in their assigned time periods to a closed interval. Two additional auxiliary nodes, a source fixed to time zero and a sink fixed to one plus the upper bound on the number of periods, are connected by arcs of lag one to every real item, and these arcs together with the item-to-item arcs define the earliest and latest allowable time period for each item.

Each item must be placed into exactly one bin in exactly one time period. The total weight of all items placed into any single bin in any single time period must not exceed the bin capacity. For every arc in the precedence graph, the lag value plus the time period of the arc's tail item must be no greater than the time period of the arc's head item. A bin-period pair is considered used whenever at least one item is assigned to it.

The goal is to minimize the total number of used bin-period pairs across the entire time horizon.
