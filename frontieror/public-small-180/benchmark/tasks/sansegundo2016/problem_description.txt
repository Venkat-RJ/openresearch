# Problem Description

Given a simple undirected graph with a finite set of vertices and a set of edges connecting pairs of distinct vertices, the task is to select a subset of vertices such that every pair of selected vertices is directly connected by an edge, and the number of selected vertices is as large as possible. The input data specifies the total number of vertices, the total number of edges, and for each vertex, the list of other vertices to which it is adjacent. The graph contains no self-loops and no duplicate edges, and every edge is bidirectional. For each vertex, a yes-or-no decision is made about whether to include it in the chosen subset. Because the selected vertices must all be mutually connected, for every pair of vertices that are not connected by an edge, at most one of the two may be selected. The goal is to maximize the total number of selected vertices.
