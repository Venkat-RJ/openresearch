# Problem Description

A telecommunications company must design a minimum-cost network to interconnect a set of target nodes through a set of potential hub sites called Steiner nodes, all located on a two-dimensional Euclidean plane. The number of target nodes and the number of Steiner nodes are each specified, and every node is identified by its coordinates. Every Steiner node has a fixed activation cost (called a node weight) that is incurred if that node is used in the network. The input data provides a connection cost for each target-to-Steiner-node pair, equal to the Euclidean distance between them, and a connection cost for each pair of distinct Steiner nodes, also equal to their Euclidean distance. No cost is negative. The costs satisfy the following property: the cost of connecting any target node to a Steiner node never exceeds the cost of connecting that target node to a different Steiner node plus the cost of connecting those two Steiner nodes, and the cost of connecting any two Steiner nodes never exceeds the cost of connecting the first to a third Steiner node plus the cost of connecting that third to the second.

The company must decide which Steiner nodes to activate, how to assign each target node to exactly one active Steiner node, and how to interconnect the active Steiner nodes. Two target nodes cannot be linked directly to each other; every target node must route through a Steiner node. A target node may only be assigned to a Steiner node that has been activated. The active Steiner nodes must be connected to one another so that they form a spanning tree, meaning the total number of edges among active Steiner nodes equals the total number of active Steiner nodes minus one. An edge between two Steiner nodes can only exist if both endpoints are active. To prevent cycles, for every subset of three or more Steiner nodes and for each individual node within that subset, the number of edges among nodes in the subset must not exceed the number of active nodes in the subset after excluding that individual node from the count.

The activation decision for each Steiner node is strictly yes or no. The assignment of each target node to a Steiner node and the presence of each edge between a pair of Steiner nodes are each allowed to take any value from zero upward; the remaining rules of the problem ensure these values will be zero or one whenever the activation decisions are zero or one.

The goal is to minimize the total network cost, which is the sum of three components: the total cost of connecting each target node to its assigned Steiner node, the total cost of edges connecting pairs of active Steiner nodes in the spanning tree, and the total activation cost of all selected Steiner nodes.
