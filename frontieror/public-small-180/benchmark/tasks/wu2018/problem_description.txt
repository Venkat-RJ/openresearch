# Problem Description

A manufacturer produces multiple items over a finite planning horizon divided into discrete periods. The production facility contains several nonidentical machines, each with its own cost and time characteristics. Not every machine can produce every item; each item has a specified subset of machines capable of producing it, and conversely each machine has a specified subset of items it can handle. For each item and each period, a known demand must be satisfied exactly on time; backlogging is not permitted.

The input data specifies the following for each instance: the number of items, periods, and machines; the demand for each item in each period; the per-unit production cost for each item on each capable machine (constant across periods); the per-unit production time for each item on each capable machine (constant across periods); a fixed setup cost incurred whenever a lot of a given item is produced on a given machine in a period (constant across periods); a setup time consumed whenever a lot of a given item is produced on a given machine in a period (constant across periods); a per-unit-per-period inventory holding cost for each item; the available capacity (in time units) of each machine in each period; and the maximum number of machines that may simultaneously produce a given item within a single period.

The planner must determine, for every item, period, and capable machine, the quantity of that item to produce on that machine in that period, and for every item and period, the amount of inventory of that item to carry at the end of that period. Additionally, for every item, period, and capable machine, the planner must decide whether a setup occurs on that machine for that item in that period. Production quantities and inventory levels may take any value from zero upward and are not restricted to whole numbers, while each setup decision is a yes-or-no choice.

Production of any positive quantity of an item on a machine in a given period requires that a setup be performed for that item on that machine in that period. If no setup is performed, no production of that item may occur on that machine in that period. The quantity that can be produced on a machine for an item in a period when a setup is performed is bounded above by the smaller of two quantities: the total remaining demand for that item from that period through the end of the horizon, and the number of units that can be produced within the machine's available capacity for that period after the setup time is deducted.

In each period, the total time consumed on each machine — comprising the production time for all units produced on that machine plus the setup time for every item that undergoes a setup on that machine — must not exceed the machine's available capacity for that period.

For each item in each period, the sum of units produced across all capable machines, plus the inventory carried over from the previous period, minus the inventory at the end of the current period, must equal the demand for that item in that period. The initial inventory of each item at the start of the first period is specified in the input data (nonnegative).

For each item in each period, the number of machines on which a setup for that item takes place must not exceed the specified maximum number of machines allowed to produce that item per period.

The goal is to minimize the total cost over the entire planning horizon, where total cost is the sum of three components: the total setup costs (summed over all items, periods, and capable machines where setups occur), the total production costs (summed over all items, periods, and capable machines, proportional to the number of units produced), and the total inventory holding costs (summed over all items and periods, proportional to the ending inventory level).
