# Problem Description

A transit agency operates a fleet of vehicles housed at several depots and must assign those vehicles to cover a given set of trips. Each trip has a fixed start time, end time, start location, and end location. Each depot has a known location and a maximum number of vehicles it can house. The input also provides, for every pair of trips where the second trip can follow the first on the same vehicle, the deadhead travel time between the end location of the first trip and the start location of the second trip; this pair is called compatible, meaning the end time of the first trip plus the deadhead travel time does not exceed the start time of the second trip. For every depot-to-trip pair, the travel time from the depot to the trip's start location is given, along with a cost equal to that travel time plus a large fixed penalty representing the cost of deploying an additional vehicle. Similarly, for every trip-to-depot pair, the travel time from the trip's end location back to the depot is given, with a cost equal to that travel time plus the same fixed penalty. For every compatible trip-to-trip pair, the deadhead cost equals the deadhead travel time.

The agency must assign every trip to exactly one vehicle. Each vehicle starts from some depot, performs a sequence of trips such that every consecutive pair in the sequence is compatible, and returns to the same depot it started from. The number of vehicles dispatched from any depot must not exceed that depot's capacity. For each depot and each trip, the number of vehicles assigned to that depot that arrive at the trip must equal the number assigned to that depot that depart from it. Likewise, the number of vehicles leaving each depot must equal the number returning to it. These balancing requirements apply at every trip and at each depot, separately for each depot.

The goal is to minimize the total cost of the assignment, which is the sum of the costs on all connections used: the deadhead travel-time costs for consecutive trip-to-trip connections plus the penalized pull-out costs for each vehicle's first trip from its depot plus the penalized pull-in costs for each vehicle's last trip returning to its depot.
