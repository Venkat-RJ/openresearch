# Problem Description

Given an undirected graph consisting of a set of vertices and a set of edges, where each edge connects two distinct vertices, the task is to color every vertex using as few distinct colors as possible while ensuring that adjacent vertices never share the same color. The input data specifies the total number of vertices, the total number of edges, and the complete list of edges as unordered pairs of vertices. A palette of candidate colors is available, whose size is determined by a greedy coloring upper bound on the chromatic number. Each vertex must be assigned exactly one color from this palette. For every edge and every color, at most one of the two endpoints of that edge may be assigned that color; moreover, if either endpoint receives a particular color, that color is considered in use. The goal is to minimize the total number of colors that are in use, that is, the count of distinct colors appearing in the assignment across the entire graph.
