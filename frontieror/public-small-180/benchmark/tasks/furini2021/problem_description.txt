# Problem Description

Consider a simple undirected graph with a specified set of vertices and a specified set of edges connecting pairs of vertices. A clique in this graph is a subset of vertices in which every pair is connected by an edge. The size of a largest clique in the graph is called the clique number. An interdictor is given a budget specifying the maximum number of edges that may be removed from the graph. After the interdictor removes edges, an adversary finds a maximum clique in the remaining graph. The interdictor's goal is to choose which edges to remove so that the size of the maximum clique in the resulting graph is as small as possible.

The input consists of the list of vertices, the list of edges, and a positive integer interdiction budget. The decision to be made is which subset of at most the budgeted number of edges to remove from the original graph. After the chosen edges are removed, the remaining graph still has the same vertex set but only the edges that were not removed. The quality of a decision is measured by the clique number of this remaining graph, i.e. the size of the largest subset of vertices in which every pair of vertices is still connected by a remaining edge. The objective is to minimize this post-removal clique number.
