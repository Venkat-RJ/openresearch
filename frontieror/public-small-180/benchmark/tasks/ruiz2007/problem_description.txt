# Problem Description

A production facility must process a set of n jobs through a series of m machines arranged in a strict sequential line, so that every job visits machine one first, then machine two, and so on through machine m. The facility must determine a single ordering (permutation) of all jobs that will be used identically on every machine; that is, the sequence in which jobs enter the first machine is the same sequence used on all subsequent machines. Each job has a known, deterministic processing time on each machine, and the input data consists of one processing time for every combination of job and machine. All jobs are independent and available for processing at time zero. Every machine is continuously available and processes exactly one job at a time, and every job can be on at most one machine at a time. Once a job begins processing on a machine it runs to completion without interruption. Setup times are included in the processing times. There is unlimited buffer storage between machines.

The machines are partitioned into two groups. A designated subset of machines are classified as no-idle machines, and the remaining machines are regular machines. Which machines belong to the no-idle subset is specified as part of the input data. On a no-idle machine, processing must be continuous once the first job in the sequence begins: the completion time of the job in each position must equal exactly the completion time of the job in the immediately preceding position plus the processing time of the current job on that machine, leaving zero gap between consecutive jobs. On a regular machine, the completion time of a job at a given position must be at least as large as the completion time of the preceding job on that same machine plus the current job's processing time, but idle gaps between consecutive jobs are permitted.

Regardless of machine type, the completion time of a job at any position on any machine from the second onward must be at least as large as the completion time of that same job on the preceding machine plus the job's processing time on the current machine, ensuring that a job cannot start on a machine until it has finished on the prior one. On the first machine, the completion time at each position must be at least the processing time of the job assigned to that position. All completion times must be zero or greater.

Each job must be placed in exactly one position of the sequence, and each position must contain exactly one job. The goal is to find the permutation of jobs that minimizes the makespan, defined as the completion time of the job occupying the last position in the sequence on the last machine.
