# Problem Description

A shipping line operates a fleet of container ships, each following a predetermined route through a subset of ports. Each port has a single continuous quay of a given length in meters. The ships fall into different types (feeder, medium, large), each with a known length in meters, a design speed, and a cubic speed-fuel consumption relationship. The problem simultaneously determines, for every ship being optimized, the exact berthing position along the quay at each port visit, the berthing start time at each port visit, and the sailing speed chosen for each voyage leg between consecutive ports on its route.

The input data specifies the following. For each port: an identifier and the total quay length. For each pair of ports: the sailing distance in nautical miles. A discrete set of feasible sailing speeds is given (for example, ten speeds ranging from 17.0 to 21.5 knots), and for each speed the travel time per nautical mile is precomputed as the reciprocal of the speed. For each ship being optimized: its length, its type, its ordered sequence of port visits (the route), and for each speed the fuel consumption in tonnes per nautical mile, which follows a cubic relationship with speed relative to the ship's design speed and design-speed fuel consumption. For each port visit of each optimized ship: an ideal berthing position (the preferred leftmost quay coordinate), a minimum handling time in hours (the service duration when berthed at the ideal position), a maximum handling time, an earliest start time before which berthing cannot begin, an expected finish time equal to the earliest start time plus the minimum handling time, and a latest finish time equal to the expected finish time plus half the difference between the maximum and minimum handling times. Five cost rates are given globally: a fuel price in USD per tonne, a handling cost in USD per hour, a delay cost in USD per hour, a waiting cost in USD per hour, and a penalty rate in USD per hour for exceeding the latest finish time. A deviation factor (beta, per meter) governs how handling time increases with distance from the ideal position. In addition, a set of external ships is given at each port; each external ship has a fixed berthing position, length, start time, and handling time and occupies quay space that optimized ships must avoid.

Each optimized ship must be assigned a quay position (measured as the leftmost point of the ship along the quay) and a berthing start time at each port it visits, and exactly one sailing speed for each leg between consecutive port visits. The berthing position plus the ship's length must not exceed the quay length at the corresponding port. The handling time at each port visit equals the minimum handling time multiplied by one plus the deviation factor times the absolute distance between the chosen berthing position and the ideal berthing position. The arrival time at each port visit after the first equals the berthing start time at the previous port visit plus the handling time there plus the travel time for the inter-port distance at the chosen speed. At the first port visit, there is no preceding voyage, and the arrival time is required only to be no later than the berthing start time at that port. Berthing may not begin before the ship arrives, and it may not begin before the earliest start time.

No two ships (whether optimized or external) may overlap in both quay space and time at the same port. For every pair of ships visiting the same port, at least one of the following must hold: one ship is positioned entirely to the left of the other along the quay, or one ship finishes its berthing period entirely before the other begins. External ships are treated identically to optimized ships for the purpose of these non-overlap requirements, but their positions, start times, and handling times are fixed inputs rather than decisions.

The delay at each port visit is the amount by which the berthing end time (start time plus handling time) exceeds the expected finish time, taken as zero if the end time is earlier. The overshoot beyond the latest finish time at each port visit is the amount by which the berthing end time exceeds the latest finish time, again taken as zero if there is no excess. The waiting time at each port visit is the difference between the berthing start time and the arrival time.

The goal is to minimize the total operational cost across all optimized ships. This total is the sum, over every port visit of every optimized ship, of the waiting cost rate times the waiting time, plus the handling cost rate times the handling time, plus the delay cost rate times the delay, plus the latest-finish-time penalty rate times the overshoot, plus, for each sailing leg between consecutive port visits, the fuel price times the fuel consumption per nautical mile at the chosen speed times the inter-port distance.
