# Problem Description

A fleet of identical vehicles operates out of a single depot to deliver goods to a set of customers. Each vehicle has the same carrying capacity. Each customer has a known demand, a location specified by coordinates, and a time window defined by an earliest service time and a latest service time. The depot also has a time window spanning the full scheduling horizon, and the demand at the depot is zero. Each customer additionally has a fixed service time that must be spent at the customer location before the vehicle can depart.

The road network connecting the depot and customers is partitioned into edge sets. Every pair of nodes (including the depot) is connected by exactly one undirected edge, and each such edge either belongs to one of the edge sets or is a free edge that does not belong to any edge set. Each edge set has a fixed access cost that the company must pay if any vehicle traverses any edge belonging to that set; once the access cost for an edge set is paid, all vehicles may use all edges in that set at no additional access charge. Edges that are free may be used by any vehicle without paying an access cost. In addition to the access costs, every arc between two nodes carries a per-use traversal cost equal to the Euclidean distance between the two nodes, incurred each time any vehicle travels that arc. The travel time on an arc from one node to another equals the Euclidean distance between the two nodes plus the service time at the origin node.

The company must decide which vehicles to deploy, which route each deployed vehicle follows, and which edge sets to access. Every customer must be visited exactly once by exactly one vehicle. Each deployed vehicle starts at the depot, visits a sequence of customers, and returns to the depot. For each customer, the total flow into that customer by a given vehicle must equal the total flow out of that customer by the same vehicle. The number of vehicles leaving the depot must equal the number returning. The total demand of all customers served by a single vehicle must not exceed the vehicle capacity. Every vehicle is assigned a visit time at every node, and that visit time must fall within the node's time window, regardless of whether the vehicle actually visits that node. If a vehicle travels directly from one node to another, the vehicle's visit time at the destination must be no earlier than the vehicle's visit time at the origin plus the travel time on that arc. An edge belonging to an edge set may only be traversed if the company has chosen to pay the access cost for that edge set; specifically, for each edge set and each customer covered by that edge set, the total number of times all vehicles enter that customer via arcs in the edge set, and separately the total number of times all vehicles leave that customer via arcs in the edge set, must each not exceed one if the edge set is accessed, and must be zero if it is not. The number of available vehicles is at most equal to the number of customers.

The goal is to minimize the total cost, which is the sum of the traversal costs over all arcs used by all vehicles plus the sum of the access costs over all edge sets that are accessed.
