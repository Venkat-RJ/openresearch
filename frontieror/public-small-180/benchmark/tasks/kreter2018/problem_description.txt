# Problem Description

A project consists of a set of activities, including two fictitious activities representing the project start and the project end. The fictitious activities have zero processing time and require no resources. Each real (non-fictitious) activity has a known integer processing time and a known integer per-period requirement for each renewable resource type. Once started, an activity runs without interruption for its full processing time. The project uses one or more types of renewable resources, and for each resource type a per-unit cost of provision is given. The amount of each resource provided is fixed for the entire project duration: every unit of a resource that is made available remains available in every period from the project start to the project end.

The activities are linked by precedence relations. Each precedence relation specifies that a particular successor activity may not start until the predecessor activity has completed, meaning the start time of the successor must be at least as large as the start time of the predecessor plus the predecessor's processing time. The project start activity must begin at time zero, and the project end activity must start no later than a prescribed project deadline. This deadline is given as input and represents an absolute upper bound on the project duration that must not be exceeded.

For each activity, the planner must choose an integer start time. The earliest and latest allowable start times for each activity can be derived from the precedence network and the deadline; an activity may only be scheduled within this allowable window. In each time period, the total demand placed on a resource type equals the sum of the per-period requirements of all real activities that are in progress during that period (an activity is in progress during a period if its start time is at or before that period and its completion time is strictly after that period). The total demand on each resource type in every period must not exceed the amount of that resource provided.

The goal is to determine start times for all activities and provision levels for all resource types so as to minimize the total resource provision cost, which is the sum over all resource types of the per-unit cost multiplied by the amount provided for that resource type, while respecting all precedence relations, the project deadline, and the requirement that resource usage never exceeds provision in any period.
