# Problem Description

A touring entertainment company plans a multi-period tour across a set of candidate venue sites to hold events (such as concerts) that attract customers from nearby population centers. The company must decide, for each period in a fixed planning horizon, which site to visit and whether to hold an event there, with the goal of maximizing total profit.

The problem involves three types of entities: venue sites where events may be held, customer locations representing nearby population centers, and time periods spanning the planning horizon. There is also a dummy starting site from which the tour departs in the first period; the distance from this dummy starting site to every venue site is zero. The input data specifies the following: the distance between every pair of venue sites, the distance between every customer location and every venue site, a cost per unit distance traveled, a maximum travel distance allowed in any single period, the population at each customer location, the capacity of each venue site (the maximum attendance it can accommodate), the revenue earned per customer attending an event at each site, the fixed cost incurred whenever an event is held at each site, the maximum number of events that may be held at each site over the entire horizon, a maximum number of consecutive periods that may contain events (denoted delta), and a performance shadow window size (denoted epsilon) that determines how many periods before and after a given period are considered when computing competitive interactions among events. Each customer location has a strictly positive self-attraction value for each period, representing the draw of substitute entertainment options in that area at that time. Each site has an attraction value for each period that reflects its inherent appeal. The attraction of customers at a given customer location to an event at a given site in a given period is computed as the product of that site's attraction value in that period and a relative time-of-week attractiveness factor, divided by the distance from that customer location to that site raised to a distance decay exponent greater than one. The relative time-of-week attractiveness factor is a value between zero and one that follows a weekly cycle, with higher values on weekends.

The company must make two types of decisions: a routing decision specifying which site the tour moves to in each period, and an event-scheduling decision specifying whether an event is held at the visited site in each period. In the first period, the tour departs from the dummy starting site and travels to exactly one venue site. In every subsequent period, the tour moves from its current site to exactly one site (which may be the same site). The site where the tour arrives in one period must be the site from which it departs in the next period. The total distance traveled in any single period must not exceed the maximum per-period travel distance. An event can only be held at a site during a period if the tour is at that site in that period. The total number of events held at any site across the entire horizon must not exceed that site's maximum event count. To ensure rest days, for every starting period t from 1 to T-delta-1, the total number of events held across all sites within the window consisting of periods t, t+1, ..., t+delta+1 (a window of delta-plus-two consecutive periods) must be at most delta.

Customer attendance at events is governed by a gravity-based attraction model that accounts for the performance shadow phenomenon, whereby events held at nearby sites within a close time window compete for the same customers. The expected proportion of the population at a given customer location that attends an event at a given site in a given period is determined by a ratio: the numerator is the attraction of that customer location to that event (which is zero if no event is held at that site in that period), and the denominator is the sum of the self-attraction of that customer location in that period plus the total attraction of that customer location to all events held at any site in any period within epsilon periods of that period (including that period itself). This proportion cannot exceed one. The expected attendance at an event held at a given site in a given period cannot exceed the sum over all customer locations of the product of each location's population and the proportion of that population attracted to the event. The attendance at any event also cannot exceed the venue's capacity.

The goal is to maximize total profit, defined as total revenue minus total costs. Total revenue is the sum over all sites and periods of the product of the per-customer revenue at each site and the expected attendance at that site in that period. Total costs consist of two components: the sum over all sites and periods of the fixed event cost at each site multiplied by whether an event is held there in that period, and the total travel cost computed as the cost per unit distance multiplied by the sum of distances traveled across all site-to-site movements in all periods.
