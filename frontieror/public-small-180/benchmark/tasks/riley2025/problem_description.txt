# Problem Description

A company operates a supply chain consisting of a set of demand sites (customers), a set of production sites, and a central depot. The company must decide which modular manufacturing units to purchase and, under each demand scenario, how to deploy and relocate those units across sites over a multi-period planning horizon to serve uncertain customer demands at minimum total cost.

Manufacturing modules come in several sizes, and for each size up to a fixed number of individual units may be purchased. All units of the same size are physically identical and interchangeable. Each unit of a given size has a known capital cost and a known production capacity, representing the maximum amount of demand that a single unit of that size can help satisfy when stationed at a production site. The input data specifies the number of demand sites, the number of production sites, the number of module sizes, the maximum number of purchasable units per size, the production capacity per unit of each size, the capital cost per unit of each size, a global maximum production limit per site per period, and a set of demand scenarios each with an associated probability. For every demand site, production site, and time period combination, a unit cost of serving demand at that demand site from that production site in that period is given (applied per unit of demand served). For every ordered pair of production sites, every module size, and every time period, a per-unit relocation cost is given for moving a module of that size between those two sites in that period. For every demand site and every time period, a penalty cost rate for unmet demand is given, applied per unit of demand left unserved. Each scenario specifies a demand quantity for every demand site in every time period.

The company must make two kinds of decisions. First, before uncertainty is resolved, the company decides for each module size how many units of that size to purchase (between zero and the size's maximum). Second, after a demand scenario is revealed, the company decides for each scenario how to operate: specifically, what fraction of each demand site's demand in each period is served from each production site, what fraction of each demand site's demand in each period goes unmet, how many units of each size are stationed at each production site and at the depot in each period, and how many units of each size are relocated between each ordered pair of sites (including moves between the depot and production sites) in each period. The fractions of demand served and unmet can take any value between zero and one, while the counts of units stationed and relocated are whole numbers.

All purchased units of a given size are initially pooled at the depot and become available to be deployed across sites in every scenario. For every demand site, every period, and every scenario, the fractions of demand served from all production sites plus the fraction left unmet must sum to exactly one. The number of units of each size at the depot in each period equals the number of purchased units of that size plus the cumulative net inflow to the depot from all production sites across all periods up to and including the current one, where net inflow is defined as units arriving at the depot minus units departing the depot in each period. Similarly, the number of units of each size at each production site in each period equals the cumulative net inflow to that site from all other sites (including the depot) across all periods up to and including the current one. At each production site, in each period and scenario, the total demand-weighted production (the sum over all demand sites of the demand quantity times the served fraction) must not exceed the aggregate capacity of the units stationed there, computed as the sum over all sizes of the number of units of that size at the site times the capacity per unit of that size. Additionally, the total demand-weighted production at any single production site in any period and scenario must not exceed a global maximum production limit.

The goal is to minimize total cost, which consists of two components. The first component is the total capital expenditure, computed as the sum over all module sizes of the capital cost per unit of that size times the number of purchased units of that size. The second component is the expected operating cost across all scenarios, weighted by scenario probabilities, which itself is the sum of three terms: the demand-weighted production and transportation cost (the sum over all production sites, time periods, and demand sites of the unit serving cost times the demand times the served fraction), the relocation cost (the sum over all ordered pairs of production sites, all module sizes, and all time periods of the per-unit relocation cost times the number of units relocated), and the unmet demand penalty (the sum over all demand sites and time periods of the penalty rate times the demand times the unmet fraction).
