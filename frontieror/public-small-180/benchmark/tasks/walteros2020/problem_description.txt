# Problem Description

Given a simple, undirected graph specified by a set of vertices numbered from zero up to one less than the total vertex count, and a set of undirected edges where each edge connects two distinct vertices with no parallel edges or self-loops, the task is to select a subset of vertices of maximum size such that every pair of selected vertices is directly connected by an edge. Such a fully interconnected subset is called a clique. The input data provides the number of vertices, the number of edges, and the complete list of edges as pairs of vertex indices. Additional metadata may include the graph's maximum degree, its degeneracy (the smallest value d such that every subgraph contains a vertex of degree at most d), the known maximum clique size, and the clique-core gap (defined as the degeneracy plus one minus the maximum clique size), but these are supplementary and not required for stating the problem.

The sole decision to be made is which vertices to include in the chosen subset. The only rule governing this selection is that for every pair of vertices in the subset, an edge must exist between them in the given graph. Equivalently, for every pair of vertices in the graph that are not connected by an edge (a "non-edge"), at most one of the two may be selected. The goal is to maximize the total number of vertices in the selected subset.
