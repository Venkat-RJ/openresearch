# Problem Description

A manufacturing facility produces multiple items over a finite planning horizon divided into discrete time periods. The input data specifies the number of items and the number of periods. For each item in each period, the data provides the demand that must be satisfied, the cost incurred for setting up production of that item, the per-unit production cost, the per-unit cost of holding inventory from one period to the next, the time required to set up the production line for that item, and the per-unit production time. Each period has a given total time capacity that limits the combined production and setup activity across all items. An initial inventory level is given for each item at the start of the first period.

The planner must determine, for each item in each period, the quantity to produce and whether to set up the production line for that item. These decisions implicitly determine the inventory carried from each period to the next. The inventory of each item at the beginning of a period, plus the quantity produced in that period, must equal the demand for that item in that period plus the inventory carried into the next period. Production of an item in a period can only occur if the production line is set up for that item in that period. In each period, the total time consumed by all setups and all production across every item must not exceed the period's time capacity. All production quantities and inventory levels must be non-negative. All inventory must be fully depleted by the end of the planning horizon, meaning no inventory remains after the final period.

The goal is to minimize the total cost, which is the sum of three components: the total setup costs summed over all items and periods where a setup occurs, the total production costs computed as the per-unit production cost times the quantity produced for each item in each period, and the total inventory holding costs computed as the per-unit holding cost times the inventory level for each item in each period.
