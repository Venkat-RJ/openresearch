# Problem Description

A manufacturing facility must process a set of jobs on a set of machines. Each job consists of an ordered sequence of operations that must be performed one after another in a fixed order specific to that job. No job has an earliest availability time; all jobs are ready for processing from the start. Each operation has a set of eligible machines on which it may be processed, and the processing time of an operation depends on which eligible machine is chosen. Every operation must be assigned to exactly one of its eligible machines.

The input data specifies the number of jobs, the number of machines, the number of operations in each job, and, for every operation, the set of machines that can perform it together with the processing time on each such machine. The time horizon is discretized into unit-length periods numbered from one up to an upper bound derived from the instance data (for example, the sum of the worst-case processing times across all operations).

The facility must determine, for each operation, which eligible machine will process it and during which time periods that processing takes place. Preemption is allowed: an operation may be interrupted at the end of any time period and resumed later, but it must always resume on the same machine to which it was assigned (no migration between machines). The total number of time periods during which an operation is actively processed must be at least the processing time associated with its assigned machine.

Each machine can process at most one operation during any single time period. The operations within each job must respect their sequential ordering: if an operation's immediate successor in the same job is being processed at some time period, then the predecessor must have completed all of its processing strictly before that time period. Specifically, once the next operation in sequence begins processing at a given time period, the total remaining processing of the current operation from that time period onward must be zero.

The makespan is the time at which the last operation of every job has finished. Because a time-period index represents the start of that period, if the final operation of any job is being processed during some time period, the job completes no earlier than that time period plus one. The goal is to minimize the makespan, that is, the earliest time by which all jobs have completed all of their operations.
