# Problem Description

A factory operates a U-shaped assembly line consisting of a fixed number of ordered stations through which a stream of identical products flows. A given collection of tasks, each with a known processing time, must be carried out on every product, and each task must be performed at exactly one station. Some pairs of tasks are linked by a precedence relation: when one task precedes another, the predecessor must be performed at the same station as the successor or at an earlier one, and when both are performed at the same station the predecessor must be done earlier in that station's sequence. Within every station, the tasks assigned to it are performed in a single linear order each cycle. Two given matrices encode the setup times that the operator at a station incurs when switching between tasks: a forward setup time matrix gives the changeover time between any two tasks performed consecutively within the same cycle (this matrix satisfies the triangle inequality), and a backward setup time matrix gives the changeover time the operator needs after finishing the last task of one cycle to be ready to start the first task of the next cycle on the same station (this matrix need not satisfy the triangle inequality). Both setup time matrices are direction-dependent: the time from one task to another may differ from the reverse.

The factory must decide, for each task, which station performs it, and the within-station order in which the tasks at every station are performed. Every station must be assigned at least one task. The time consumed in one cycle at a station equals the sum of the processing times of the tasks assigned to it, plus the forward setup times between every pair of tasks that are consecutive in that station's order, plus the backward setup time from the station's last task back to its first task. The cycle time of the line is the largest such per-station time across all stations.

The goal is to choose the task-to-station assignment and the per-station ordering so as to minimize the cycle time, subject to all task-to-station, precedence, and within-station-ordering rules above.
