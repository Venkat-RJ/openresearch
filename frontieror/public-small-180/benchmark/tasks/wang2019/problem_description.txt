# Problem Description

A freight transportation carrier operates a service network represented as a directed graph with a given set of nodes (terminals) and a given set of directed arcs (service links between terminals). The carrier must transport a set of commodities through this network, where each commodity has a known origin node, a known destination node, and a known demand quantity that must be shipped in full from origin to destination. The carrier operates a heterogeneous fleet consisting of several vehicle types, each with a known capacity and a known fixed cost per arc for deploying one vehicle of that type on that arc. There is no limit on the number of vehicles available for any type. Each combination of commodity and arc has a known unit flow cost, so that the cost of shipping a given commodity along a given arc equals that unit flow cost multiplied by the quantity of that commodity routed on that arc.

The carrier must decide two things simultaneously: how to route the flow of each commodity through the network, and how many vehicles of each type to assign to each arc. The flow of each commodity must be balanced at every node: at each node the total outgoing flow of a commodity minus its total incoming flow equals the commodity's demand if that node is the commodity's origin, equals the negative of the demand if that node is the commodity's destination, and equals zero at all other nodes. On every arc, the total flow of all commodities combined must not exceed the total capacity provided by the vehicles assigned to that arc, where total capacity is the sum over all vehicle types of each type's capacity multiplied by the number of vehicles of that type on the arc. The flow of each commodity on each arc cannot be negative. The number of vehicles of each type assigned to each arc must be a whole number that is zero or greater. The number of vehicles of each type must be balanced at every node, meaning that for each vehicle type, the total number of vehicles of that type entering a node across all incoming arcs must equal the total number leaving that node across all outgoing arcs. This balance requirement ensures that vehicles follow cyclical routes through the network so that the fleet is conserved.

The goal is to minimize the total cost, which is the sum of two components: the total flow cost, computed as the sum over all arcs and all commodities of the unit flow cost times the amount of that commodity routed on that arc, and the total fixed vehicle cost, computed as the sum over all arcs and all vehicle types of the fixed cost times the number of vehicles of that type assigned to that arc.
