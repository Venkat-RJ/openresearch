# Problem Description

A steel tube manufacturer operates a cutting machine that slices a continuous steel tube into smaller pieces of various product types. The machine has a fixed length, and it is configured using cutting patterns, each of which specifies how many pieces of each product type are cut simultaneously in a single pass. The machine may use multiple distinct patterns, and each pattern may be repeated multiple times. The input field `problem_type` selects one of three machine variants. In the open-ended variant, each repetition can additionally produce one extra piece of any product type beyond the configured pattern. In the closed-ended variant, the end wall prevents all such extra pieces. In the open-ended variant with knife-dependent setups, extra pieces are allowed, but setting up a used pattern incurs an additional cost proportional to the number of knives in that pattern. The number of knives equals the total number of pieces cut simultaneously by the pattern.

The input data consists of a set of products and a set of available patterns. Each product has a known length and a known demand (the number of pieces required). The cutting machine has a known total length. Two time-cost parameters are always given: a fixed setup time incurred once for each pattern that is used, and a cutting time incurred once per repetition of any pattern. Knife-dependent instances additionally provide the setup cost per knife. Closed-ended instances explicitly indicate that extra-piece variables are forced to zero. A large number, equal to the maximum demand among all products, caps the number of repetitions any single pattern may have. For each product, the maximum number of pieces of that product that can fit within a single pattern is also given.

The manufacturer must decide which patterns to use, how many pieces of each product type to include in each pattern, how many times to repeat each pattern, and, when the machine is open-ended, how many extra pieces of each product type to produce. The total number of units of each product produced by a given pattern equals the number of pieces of that product specified in that pattern multiplied by the number of repetitions of that pattern. If a pattern is not used, no pieces may be assigned to it. If a pattern is used, the sum of the lengths of all pieces assigned to it must not exceed the machine length. A pattern may have repetitions only if it has been set up for use, and its repetition count is limited by the large number described above. For every product, the total production from all patterns plus any permitted extra pieces must meet or exceed demand. In open-ended variants, the total number of extra pieces across all products must not exceed the total number of pattern repetitions. In the closed-ended variant, every extra-piece quantity must be zero. To avoid interchangeable orderings, patterns are ordered so that each repetition count is at least as large as the next. Piece counts and repetition counts must be nonnegative integers. Extra-piece quantities must be nonnegative. For a knife-dependent instance, the solution must also report each pattern's knife count, equal to the sum of its per-product piece counts.

The goal is to minimize total time: fixed setup times for used patterns plus cutting times for all pattern repetitions. For a knife-dependent instance, the objective also includes the setup cost per knife multiplied by the total number of knives across all patterns.
