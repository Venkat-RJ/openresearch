# Problem Description

An independent power producer owns a single thermal generator and must decide, over a multi-period planning horizon, when to turn the generator on or off and how much electricity to produce at each point in time, in order to sell power into a real-time electricity market where prices are uncertain. The uncertain future prices are represented by a scenario tree: a rooted tree in which the root corresponds to the first time period, each non-root node has a unique parent, and each node may branch into multiple children representing different possible price realizations in the next period. Every node in the tree is associated with a time period, an electricity price in dollars per megawatt-hour, and a probability weight reflecting the likelihood of reaching that node from the root. The total number of time periods, the branching structure of the tree, and all node-level prices and probabilities are given as input.

The generator is characterized by several physical parameters, all provided as input data: an upper generation limit and a lower generation limit, both in megawatts, that bound the output whenever the generator is running; a ramp-up rate and a ramp-down rate, both in megawatts per period, that limit how much generation can increase or decrease between a node and its parent; a minimum-up time stating the number of consecutive periods the generator must remain on after being started; a minimum-down time stating the number of consecutive periods the generator must remain off after being shut down; a fixed startup cost and a fixed shutdown cost, both in dollars, incurred each time the generator transitions from off to on or from on to off, respectively; and a fuel cost function that gives the fuel cost in dollars as a nondecreasing convex piecewise-linear function of the generation level in megawatts.

At every node the producer must choose whether the generator is on or off and, if on, the generation level. At every non-root node the producer must also determine whether a startup occurs, meaning the generator was off at the parent node and is now on. A shutdown occurs at a non-root node whenever the generator was on at the parent node and is now off; the shutdown event is fully determined by the on/off statuses at the node and its parent together with the startup decision, specifically it equals the parent on/off status minus the current on/off status plus the startup indicator.

The following operational rules govern these choices. If the generator starts up at a node, it must remain on at every descendant node reachable within a number of periods equal to the minimum-up time minus one, counting from the startup node. If the generator shuts down at a node, it must remain off at every descendant node reachable within a number of periods equal to the minimum-down time minus one, counting from the shutdown node. A startup can occur at a node only if the generator is on at that node and was off at its parent. The generation level at any node where the generator is off must be zero, and at any node where the generator is on it must lie between the lower and upper generation limits. Between any node and its parent, the increase in generation cannot exceed the ramp-up rate when the parent is on, but generation may jump freely from zero to any feasible level when the generator was previously off; symmetrically, the decrease in generation cannot exceed the ramp-down rate when the current node is on, but generation may drop freely to zero when the generator shuts down. Decisions at each node depend only on information revealed along the path from the root to that node, which is enforced by the tree structure itself.

The goal is to maximize total expected profit across the scenario tree. Expected profit is the probability-weighted sum, over all nodes, of the revenue from selling electricity at that node's price minus the costs incurred at that node. The costs at each node comprise the startup cost if a startup occurs, the shutdown cost if a shutdown occurs, and the fuel cost of producing at the chosen generation level.
