# Problem Description

A distributed processing system consists of a set of clients and a set of servers. Each client has a known demand value drawn from a continuous range, and each server has a known processing rate. The linear processing cost of assigning a particular client to a particular server equals the product of that client's demand and that server's processing rate. In addition to these linear costs, there are pairwise quadratic interaction costs that arise whenever two client-server assignments are both active simultaneously. A quadratic cost is specified for each pair of client-server assignments and represents the joint cost incurred when both assignments are in effect at the same time. Two types of quadratic interactions exist: adjacent interactions, which occur between two assignments that share the same server, and out-of-star interactions, which occur between two assignments directed at different servers. For adjacent interactions where two clients share the same server, the quadratic cost equals the sum of the two individual linear processing costs of those assignments. Out-of-star interaction costs, when present, are specified independently for a subset of cross-server assignment pairs at a given density level.

Each client must be assigned to exactly one server, but a server may serve any number of clients. The total cost of an assignment consists of two additive components: the sum of linear processing costs over all active client-server assignments, and the sum of quadratic interaction costs over all pairs of assignments that are both active. Specifically, for every pair of active assignments that has a specified quadratic cost, that cost coefficient is added to the total. The goal is to find an assignment of every client to exactly one server that minimizes this total cost.

The input data provides the number of clients, the number of servers, a demand value for each client, a processing rate for each server, a matrix of linear costs for each client-server pair, and a list of quadratic cost entries each specified as a tuple of two client-server pairs together with the associated pairwise cost value. A density parameter indicates what fraction of non-adjacent assignment pairs carry a nonzero quadratic cost; when this density is zero, only adjacent (same-server) quadratic interactions exist.
