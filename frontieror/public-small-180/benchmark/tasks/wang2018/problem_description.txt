# Problem Description

A container terminal must jointly plan berth allocation, quay crane (QC) assignment, and yard storage assignment for a set of incoming vessels (num_vessels) over a cyclical weekly planning horizon divided into discrete time steps (H), where each time step represents a fixed number of hours (time_step_duration_hours). The terminal has a set of berths along the quay (num_berths) and a pool of quay cranes (num_QCs) shared across all berths, with a maximum number of QCs available at each time step (QC_capacity_per_timestep, indexed by [time step]). The storage yard is partitioned into subblocks (num_subblocks). The maximum handling time across all vessels and all their QC profiles defines an extension length (E), and the full time horizon spans from time step one through time step H plus E. For each vessel the following data are given: the number of containers to be loaded (loading_containers) and unloaded (unloading_containers), the number of yard subblocks that must be reserved for the vessel (reserved_subblocks), a per-vessel penalty cost coefficient for deviations from its expected service times (penalty_cost_coefficient), a feasible service time window expressed as the earliest and latest permissible start and end time steps (feasible_time_window, indexed by [start, end]), an expected service time window within which service ideally occurs (expected_time_window, indexed by [start, end]), and a set of candidate QC profiles (qc_profiles, indexed by [profile]). Each QC profile specifies a handling time in time steps (handling_time) and the number of QCs used in each successive time step of that handling duration (qc_per_timestep, indexed by [time step within profile]). The loading route length from each subblock to each berth is given (loading_route_lengths_D_L, indexed by [subblock][berth]), as is the average unloading route length from each berth to all subblocks in the yard (average_unloading_route_lengths_D_U, indexed by [berth]). A single global operation cost coefficient scales the yard transportation costs (penalty_cost_coefficient_co).

The terminal must make the following decisions for every vessel: assign exactly one berth, select exactly one QC profile from that vessel's candidate set, choose a handling start time step within the planning horizon, and reserve the required number of distinct yard subblocks. Each subblock may be reserved for at most one vessel. The handling end time step for a vessel equals its start time step plus the handling time dictated by the chosen QC profile minus one.

Every vessel's handling start time step must fall no earlier than the first time step of its feasible service window, and its handling end time step must fall no later than the last time step of that window. When two vessels are assigned to the same berth, one must completely finish handling before the other begins; that is, a strict time-sequence must exist between every pair of vessels sharing a berth. The number of QCs in use at each time step is determined by summing, over all vessels, the QC usage dictated by their chosen profiles and start times. Because the plan repeats weekly, QC capacity is enforced with periodicity: for each time step in the range from E plus one through H the total QC usage at that step must not exceed the available capacity, and for each time step from one through E the sum of QC usage at that step and at its twin step H time steps later must not exceed the available capacity. Similarly, for each berth the gap between the earliest start time step and the latest end time step among all vessels assigned to that berth must not exceed H minus one, which ensures that the berth schedule can wrap around consistently from one week to the next without conflict.

The goal is to minimize total cost, which is the sum of three components. The first is the penalty cost: for each vessel, the penalty cost coefficient multiplied by the sum of two terms — the amount by which the handling start time step precedes the first time step of the expected window (if it does) and the amount by which the handling end time step exceeds the last time step of the expected window (if it does). The second is the loading transportation cost: for each vessel, for each subblock reserved for that vessel and each berth at which the vessel dwells, the operation cost coefficient multiplied by the loading route length between that subblock and that berth, multiplied by the number of loading containers divided by the number of reserved subblocks. The third is the unloading transportation cost: for each vessel, the operation cost coefficient multiplied by the average unloading route length from the vessel's assigned berth, multiplied by the number of unloading containers.
