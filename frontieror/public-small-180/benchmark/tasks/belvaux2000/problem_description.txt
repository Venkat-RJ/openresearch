# Problem Description

A manufacturing facility produces NI distinct items using NK machines over a planning horizon of NT discrete periods. The instance data specifies the demand for each item in each period (demand, indexed by item and period), each machine's per-period production capacity (capacity_C, indexed by machine) and startup capacity loss (startup_time_sigma, indexed by machine), a uniform setup cost (setup_cost_f) and a uniform startup cost (startup_cost_g) applying to all items and machines, item-specific per-unit inventory holding costs (holding_cost_h, indexed by item) and backlogging penalty costs (backlogging_cost_e, indexed by item), and initial inventory (initial_stock_s0) and backlog levels (initial_backlog_r0) for each item.

In each period, for each item, the prior period's closing inventory plus total production of that item across all machines minus the prior period's closing backlog must equal the current demand plus this period's closing inventory minus this period's closing backlog. Each machine may produce at most one item per period and can only produce an item it is set up for. Each machine has a fixed per-period production capacity that does not vary over time. A startup is incurred on a machine precisely when it becomes set up for an item it was not set up for in the immediately preceding period; no machine is considered set up for any item before the first period. Each startup consumes a machine-specific amount of that period's production capacity, so the quantity produced on a machine plus any startup capacity loss cannot exceed the machine's capacity. Furthermore, if a machine was set up for a certain item in the previous period, that same item cannot incur a startup on that machine in the current period, and every different item assigned to that machine in the current period must incur a startup.

The facility pays the setup cost each period a machine is set up for any item, the startup cost for each startup event, the item-specific holding cost for each unit of inventory at each period's end, and the item-specific backlogging penalty for each unit of backlog at each period's end. The goal is to choose production quantities, inventory and backlog levels, and setup and startup schedules for every item, machine, and period so as to minimize the total of all setup, startup, holding, and backlogging costs over the entire horizon.
