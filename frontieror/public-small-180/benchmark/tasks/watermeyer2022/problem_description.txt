# Problem Description

A project consists of a set of activities, each of which must be assigned a nonnegative integer start time. The activities include a fictitious project-start activity (numbered zero) and a fictitious project-end activity (numbered one more than the count of real activities), both with zero processing time, along with the real activities, each having a given positive integer processing time. Once started, every real activity runs without interruption for its full processing time; an activity that starts at a given time occupies the time periods from that start time plus one through the start time plus the activity's processing time.

The project-start activity must begin at time zero. Pairs of activities are linked by start-to-start temporal relationships: for each linked pair, the start time of the second activity minus the start time of the first must be at least a specified integer time lag. When the lag is nonnegative it enforces a minimum separation; when it is negative it effectively imposes a maximum separation between the two starts. A maximum project duration is enforced by including a temporal relationship from the project-end activity to the project-start activity whose lag equals the negative of the deadline, ensuring that the project-end activity starts no later than that deadline.

The project uses a set of partially renewable resources. Each such resource is associated with a designated subset of time periods drawn from the full planning horizon (one through the maximum project duration). Each resource also has a nonnegative integer capacity and, for every activity, a nonnegative integer per-period demand. The total consumption of a resource by an activity equals the activity's per-period demand for that resource multiplied by the number of time periods in the resource's designated subset during which the activity is in execution. The total consumption of a resource across all activities in the project must not exceed that resource's capacity. This differs from classical renewable resources in that the capacity bound applies to the aggregate consumption over the resource's entire designated period subset rather than to the usage in any single period.

The input data for an instance specifies the number of real activities; the processing time of each activity; the set of temporally linked activity pairs together with their time lags; the maximum project duration; the number of partially renewable resources; and for each resource its designated period subset, its capacity, and the per-period demand of every activity for that resource.

The goal is to choose a nonnegative integer start time for every activity so as to minimize the start time of the project-end activity, which represents the overall project duration, while satisfying all temporal relationships between activity pairs and ensuring that the total consumption of every partially renewable resource does not exceed its capacity.
