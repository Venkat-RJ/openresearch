# Problem Description

An airport operates an outbound baggage handling system in which outgoing flights must each be assigned to exactly one carousel and scheduled for baggage handling over a discrete planning horizon divided into evenly spaced time periods (for example, five-minute intervals). The entities involved are a set of outgoing flights, a set of carousels partitioned into distinct carousel types, a set of discrete time periods spanning the planning day, and a set of designated peak intervals (disjoint subsets of consecutive periods during which workload leveling is critical). Each carousel type is characterized by four capacity parameters: the conveyor belt capacity (maximum number of bags that can be on the carousel in any single period), the number of container parking positions, the number of working stations, and the number of parking positions per working station. The carousels belonging to different types do not overlap.

Each flight has a known baggage arrival profile specifying the number of bags arriving in each period of its handling duration, a required number of containers, a time window defined by an earliest and a latest permissible start period for baggage handling, and a fixed end period by which handling must conclude. The number of working stations that may be assigned to a flight at a carousel of a given type is bounded below and above: the lower bound is determined by the maximum of one and the floor of the ratio of the flight's required containers to the parking positions per working station, and the upper bound is derived from the ceiling of that same ratio plus an additional station when the remainder is greater than one. These per-type bounds induce overall minimum and maximum working station counts for each flight across all carousel types. A central storage system with a fixed bag capacity receives baggage that arrives before a flight's handling has begun; once handling starts, stored bags are depleted from the storage to the assigned carousel at a constant rate. The storage depletion cannot begin before the handling start, and must commence early enough (by an offset that depends on the handling start time, typically several periods before the handling end) to guarantee all stored bags are transferred to the carousel well before baggage handling concludes. Each flight's baggage handling schedule is described by a start time tuple consisting of the start time of baggage handling at the carousel and the start time of storage depletion, and the set of feasible start time tuples for a flight depends on the number of working stations assigned, the flight's time window, and the depletion offset rule. Each working station processes bags at a fixed rate (for instance, eight bags per five-minute period), and the storage system depletes bags at its own fixed rate (for instance, nineteen bags per five-minute period).

Two derived parameters are computed from each flight's arrival profile, the assigned number of working stations, and the chosen start time tuple: the flight's workload on a carousel during each period (the number of bags present on the conveyor belt attributable to that flight), and the amount of baggage stored in the central storage during each period for the given start time tuple.

The airport must decide, for every flight, which carousel to assign it to, how many working stations to allocate (within the type-specific bounds), and which feasible start time tuple to select. Each flight must receive exactly one such combined assignment. In every period, the total number of working stations used across all flights actively being handled at a carousel must not exceed that carousel type's working station capacity. Similarly, the total number of containers parked across all flights at a carousel in any period must not exceed the carousel type's parking position capacity. The total amount of baggage stored in the central storage across all flights in any period must not exceed the storage system's capacity. The storage capacity may be tightened on a per-period basis by subtracting the baggage known to have arrived before the earliest possible handling start of flights that have not yet begun handling, including any early baggage that arrived before the start of the planning horizon.

The planning horizon is partitioned into several disjoint peak intervals during which carousel utilization is monitored. A carousel's utilization in a period is the ratio of its total workload (the sum of workload contributions from all flights assigned to it in that period) to its conveyor belt capacity. The airport specifies a target utilization strictly less than one. Deviations above the target utilization are measured against an ordered sequence of threshold values (for example, thirteen thresholds ranging from 0.1 through 0.2 up to 0.9, then 1, 2, 10, and 100). For each carousel and each peak interval, at most one threshold level may be flagged as exceeded. Each threshold level carries a penalty that grows steeply with the threshold index (for instance, following the pattern where each penalty equals its position in the sequence raised to the power of that same position). The linking rule between utilization and threshold violations requires that, for every carousel, every period within a peak interval, the utilization minus the sum of threshold values weighted by their corresponding threshold-exceeded indicators must not exceed the target utilization.

The goal is to minimize the total penalty summed over all carousels, all threshold levels, and all peak intervals, thereby finding a flight-to-carousel assignment and baggage handling schedule that keeps carousel utilization as close to or below the target as possible during peak times while respecting all working station, parking position, and central storage capacity limits.
