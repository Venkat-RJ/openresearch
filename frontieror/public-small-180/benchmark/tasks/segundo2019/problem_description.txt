# Problem Description

Given a simple undirected graph with a specified set of vertices and a specified set of edges, where each edge carries a strictly positive weight, the task is to select a subset of vertices that forms a clique, meaning every pair of selected vertices must be directly connected by an edge in the graph. The input data provides the full list of vertices, the full list of edges (each identified by its two endpoint vertices), and a weight for every edge. The edge weight for an edge is computed as the sum of its two endpoint vertex indices taken modulo 200, plus one, though in general any positive weight may be supplied.

The goal is to choose which vertices belong to the clique and, correspondingly, which edges have both endpoints inside the clique, so as to maximize the total weight summed over all edges whose two endpoints are both selected. An edge is considered part of the solution only if both of its endpoint vertices are chosen; specifically, including an edge requires that its first endpoint is selected, and separately requires that its second endpoint is selected. If either endpoint is excluded, that edge contributes nothing to the total weight. For every pair of vertices that are not connected by an edge in the graph (a "non-edge"), at most one of the two may be selected, which enforces the requirement that the chosen vertices form a clique.
