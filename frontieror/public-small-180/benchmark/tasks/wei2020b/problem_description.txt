# Problem Description

A warehouse holds a collection of identical bins and a set of items that must all be packed into those bins. Each item has two attributes: a weight and a volume. Every bin has the same weight limit and the same volume capacity. Every item's weight is strictly positive and does not exceed the bin's weight limit, and every item's volume is strictly positive and does not exceed the bin's volume capacity. The task is to assign every item to exactly one bin so that, within each bin, the total weight of the assigned items does not exceed the bin's weight limit and the total volume of the assigned items does not exceed the bin's volume capacity. Each item must appear in exactly one bin; it cannot be split across bins or left unpacked. The goal is to minimize the total number of bins used.
