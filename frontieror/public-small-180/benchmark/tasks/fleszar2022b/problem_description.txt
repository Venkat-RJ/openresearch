# Problem Description

A company has a collection of items and a set of knapsacks. Each item has a positive integer weight and an individual integer value. Additionally, for every pair of distinct items, there is a pairwise integer value that is earned only when both items in the pair are placed into the same knapsack; individual and pairwise values may be positive, zero, or negative. All knapsacks have identical integer capacities. The company must decide which items to pack and into which knapsacks, subject to the following rules. Each item may be placed in at most one knapsack, and some items may be left unpacked entirely. The total weight of items placed in any single knapsack must not exceed that knapsack's capacity. The pairwise values are symmetric, meaning the value associated with a pair of items is the same regardless of which item is listed first. The goal is to maximize the total collected value, which is the sum, over all knapsacks, of the individual values of the items packed in that knapsack plus the pairwise values earned by every pair of items that share that knapsack. The input data specifies the number of items, the number of knapsacks, the weight of each item, the individual value of each item, the pairwise value for each pair of distinct items, and the common capacity of all knapsacks. All problem parameters are integers, and items are indexed in order of non-decreasing weight. The common knapsack capacity is set to the floor of the quantity 0.8 times the sum of all item weights divided by the number of knapsacks.
