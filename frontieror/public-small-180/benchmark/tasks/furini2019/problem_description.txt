# Problem Description

Given an undirected graph with a specified number of vertices and a list of edges connecting pairs of those vertices, the task is to select the largest possible subset of vertices such that every pair of selected vertices is directly connected by an edge. The input data consists of the total number of vertices, the total number of edges, and the complete list of edges, where each edge is an unordered pair of distinct vertex identifiers (zero-indexed). For each pair of vertices that are not connected by an edge in the graph, at most one of the two may be selected. The goal is to maximize the number of selected vertices, which equivalently means finding the largest fully connected subgraph.
