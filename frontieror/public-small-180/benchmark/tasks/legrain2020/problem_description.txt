# Problem Description

A hospital must build a complete schedule for a set of nurses over a planning horizon spanning a given number of whole weeks, where the total number of days equals seven times the number of weeks. Each day is divided into a set of named shifts, and every nurse possesses one or more skills from a known set of skills. An assignment is a particular shift on a particular day. For every combination of assignment and skill, the input specifies both a minimum demand and an optimal demand in nurses who perform that skill on that assignment. Each nurse has a personalized contract that specifies a minimum and maximum total number of worked days over the entire horizon, a minimum and maximum number of consecutive worked days, a minimum and maximum number of consecutive days off, and a maximum number of worked weekends over the horizon. Each nurse also has a set of preferred-off assignments, representing specific day-shift pairs that the nurse wishes not to work. For each shift, the input gives a minimum and maximum number of consecutive assignments to that same shift. A set of forbidden shift successions is given as pairs of shifts such that a nurse who works the first shift on some day may not work the second shift on the immediately following day. Finally, the input provides a unit penalty weight for each of the following categories: insufficient staffing for optimal coverage, consecutive worked-days violations, consecutive same-shift violations, consecutive days-off violations, preference violations, incomplete-weekend violations, total-assignment violations, and total worked-weekend violations.

The scheduler must decide, for each nurse and each day, whether the nurse works or rests, and if the nurse works, which shift and which skill the nurse performs. A nurse may work at most one shift per day and may only cover demand for a skill that the nurse actually possesses. The number of nurses performing a given skill on a given assignment must be at least the minimum demand for that skill and assignment; this is a hard requirement that cannot be violated. If the number of nurses performing a given skill on a given assignment falls short of the optimal demand, each missing nurse is penalized at the insufficient-staffing unit weight. A nurse may not work a shift on one day followed by a forbidden successor shift on the next day; this too is inviolable.

The remaining scheduling rules may be violated at a cost. For each nurse, the number of consecutive worked days within any uninterrupted work stretch should lie between the nurse's minimum and maximum consecutive worked-days bounds; each day of deviation is penalized at the consecutive worked-days unit weight. Similarly, the number of consecutive assignments to the same shift within any uninterrupted stretch of that shift should lie between that shift's minimum and maximum consecutive same-shift bounds; each assignment of deviation is penalized at the consecutive same-shift unit weight. The number of consecutive days off within any rest period should lie between the nurse's minimum and maximum consecutive days-off bounds; each day of deviation is penalized at the consecutive days-off unit weight. Each time a nurse is assigned to a day-shift pair that appears in the nurse's preferred-off set, the preference unit weight is incurred. Weekends should be worked completely or not at all: if a nurse works exactly one of Saturday and Sunday in any given week, the incomplete-weekend unit weight is incurred for that weekend. The total number of worked days over the entire horizon for each nurse should lie between the nurse's minimum and maximum total assignment bounds; each day of deviation in either direction is penalized at the total-assignment unit weight. The number of weekends in which the nurse works at least one day should not exceed the nurse's maximum worked-weekends limit; each weekend in excess is penalized at the worked-weekend unit weight.

The goal is to minimize the total penalty, which is the sum of all insufficient-staffing penalties across all assignments and skills, all consecutive worked-days and consecutive same-shift penalties across all nurses, all consecutive days-off penalties across all nurses, all preference penalties across all nurses, all incomplete-weekend penalties across all nurses, all total-assignment deviation penalties across all nurses, and all excess worked-weekend penalties across all nurses.
