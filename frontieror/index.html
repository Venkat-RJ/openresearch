Verify the archive

Download scheduling evidence, large-campaign evidence and small-task evidence. Extract into the same folder. Use Python 3.10 or newer:

python3 frontieror/tools/verify_public_release.py

This command checks current public hashes, selected-source mappings, saved-solution feasibility and scheduling statistics. Original file identities are documented in the technical release records. The verifier does not run optimization or access the network.
